# NIKKI BEAUTY MAISON — Static Website

Simple static website for Nikki Beauty Maison. Files included:

- `index.html` — main page
- `styles.css` — styles and animations
- `script.js` — small interactions (nav toggle, smooth scroll, reveal)
- `assets/placeholder-logo.svg` — logo placeholder

To preview locally, open `index.html` in your browser or run a simple static server, e.g.:

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000
```
